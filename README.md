# 몬스테라키우기

## 게임

`index.html` 한 파일짜리 웹 게임. 브라우저로 열면 바로 실행되고, 기록은 그 브라우저에 저장된다.

- 잎 1장 새싹에서 잎 15장 대형 몬스테라까지 키운다. 앱을 꺼도 실제 시간이 흐른다.
- 돌보기: 물주기 · 분무 · 영양제 · 잎 닦기 · 자리 옮기기(어두운 구석 / 커튼 친 창가 / 남향 직사광) · 상점
- 화분이 꽉 차면 분갈이(3호 → 5호 → 7호 → 10호), 잎 8장 이후로는 모스폴 지지대가 있어야 자란다.
- 빛이 부족하면 새 잎이 하트 모양 그대로 나오고, 밝은 간접광에서 잎이 갈라지고 구멍이 생긴다.
- 과습이면 뿌리파리, 건조하면 응애가 생긴다. 화면에서 눌러 잡는다.
- 다 키우면 꺾꽂이로 다음 세대를 시작한다.
- 규칙 코드를 돌려 잰 완성 기간(커튼 친 창가 기준): 하루 2번 돌보면 14일, 하루 1번이면 17일. 어두운 구석에 두면 33.5일.

몬스테라 키우기 게임 조사 기록 (조사일: 2026-10-13)

## 결론

**몬스테라를 키우는 것 자체가 목적인 게임은 오늘의집 앱 안의 「오늘의가든」 하나만 확인됐다.**
나머지는 몬스테라가 여러 식물 중 하나로 들어 있거나, 이름만 「몬스테라」이고 식물 키우기와는 관계없는 게임이다.

---

## 1. 몬스테라를 실제로 키우는 게임

| 게임 | 어디서 | 확인된 내용 |
|---|---|---|
| **오늘의가든** | 오늘의집 앱 안 | 가상 식물을 최종 6단계까지 키우면 실물 몬스테라를 0원 주문으로 배송받음. 출석·미션으로 물과 영양제를 받고, 영양분이 80 이상일 때 물을 주면 경험치 2배. 한 후기 기준 26일 소요(8/13 시작 ~ 9/6 종료). 오늘의집 스토어에 「몬스테라 오늘의가든 사은품용 비매품」 상품이 있어 실물 배송이 실제로 이루어졌음을 알 수 있음 |
| **Kinder World** | iOS·안드로이드, 무료 | 심리 안정용 실내 식물 키우기 게임(개발사 Lumi Interactive). PocketGamer 업데이트 기사에 몬스테라가 키울 수 있는 식물로 나옴. 앱스토어 마지막 업데이트 2026-03-24 |

### 오늘의가든 세부

- **물·영양제 얻기**: 매일 출석체크(연속 출석일수록 보상 증가), 데일리 미션(오늘의 콘텐츠 보기, 오늘의딜 구경 등), 친구와 주고받기
- **경험치**: 물을 주면 경험치가 오르고 100%가 되면 다음 레벨. 영양분 80 이상에서 물을 주면 2배
- **팁(후기)**: 레벨 1~3에서는 영양제를 아낄 것. 레벨 5 도달 시 고급 영양제 6개 보상. 5단계 이후 성장이 확연히 느려짐
- **행운추첨**: 바로수확권, 레벨 1단계 성장권, 고급영양제 3개 등이 나올 수 있음
- **수확**: 최종 레벨(6) 도달 → 배송지 입력 → 쿠폰으로 0원 주문

### 오늘의가든 주의점

- 찾은 자료 대부분이 2023~2024년 글이다. **2026년 현재 몬스테라를 고를 수 있는지는 확인하지 못했다.**
- 고를 수 있는 식물은 시기마다 달랐다.
  - 4종일 때: 계절 꽃다발·몬스테라·방울토마토·홍콩야자
  - 7종일 때: 몬스테라·스킨답서스·홍콩야자·커피나무·바질 재배키트·루꼴라 재배키트·계절 꽃다발
- 오늘의집 페이지에 「서비스 운영 2024.09.08 ~ 2027.09.07」 표기가 있다. 게임 자체의 운영 기간인지는 분명하지 않다.
- 한 개인 블로그에 「24년 12월 31일부로 미니게임 종료」라고 적혀 있다. 공식 공지는 찾지 못했다.
- 2023년 기사 기준 이용자 약 10만 명.

## 확인 한계

- 조사 환경의 네트워크 정책 때문에 store.steampowered.com, itch.io, chloe-one.com 등 **원문 페이지 직접 접속이 막혔다(프록시 403).** 위 내용은 전부 검색엔진 결과에서 가져온 것이며, 원문 페이지를 직접 다 읽은 것은 아니다.
- 네이버 블로그는 검색 도구 쪽에서 접근이 막혀 검색 대상에서 빠졌다.
- Monster Monstera 평점은 검색마다 다르게 나와(2.5점·2명 / 2.0점·1명) 확정하지 않았다.
